# Пошагово

Сайт с пошаговыми инструкциями и чек-листами: собрать ПК, оформить справку, сдать лабу, поставить Docker. Читаешь по шагам, отмечаешь пройденное, ставишь оценки и комментарии. Автор видит, где люди бросают, и улучшает инструкцию.

## Запуск

```
pip install -r backend/requirements.txt
fastapi run backend/main.py
```

Открывай http://127.0.0.1:8000. Сервер отдаёт и сайт, и API. При первом запуске создаётся `backend/app.db` и загружаются пять примеров из `backend/seed.json`. Хочешь чистую базу — удали `app.db` и запусти заново.

## Что умеет

- *Каталог* — разделы, сортировка, фильтр «проверено экспертом».
- *Прохождение* — шаг за шагом, чек-листы, прогресс-бар.
- *Кабинет автора* — создание, редактирование с версиями, удаление.
- *Комментарии и «полезно / не полезно»* — один голос на шаг.
- *Предложения улучшений* — автор принимает или отклоняет.
- *Форк* — своя версия чужой инструкции со ссылкой на оригинал.
- *Роли* — ученик и эксперт, у эксперта отметка.
- *Умный поиск* — по названию, разделу и шагам, с окончаниями.
- *Рейтинг полезности* — доля «полезно», по ней сортировка.
- *Аналитика* — до какого шага доходят, где бросают, сколько времени на шаг.
- *Помощник автора* — разбивает текст на шаги, проверяет черновик.
- *Мобильная версия*.
- *Офлайн-режим* — прогресс хранится в браузере.
- *Экспорт в PDF*.
- *Встраивание* — `iframe` без шапки.

## Файлы

```
index.html, style.css   страница и оформление
app.js                  логика и запросы к API
data.js                 разделы и иконки
sw.js                   офлайн-режим
backend/main.py         сервер: API и сайт
backend/seed.json       примеры инструкций
```

Бэкенд на FastAPI, данные в SQLite. Фронтенд — чистые HTML, CSS, JS без сборки.

| Таблица | Что хранит |
|---|---|
| `users` | имя, роль, хэш пароля с солью |
| `sessions` | токены входа |
| `tasks` | инструкции, шаги в JSON |
| `comments` | комментарии к шагам |
| `votes` | оценки шагов |
| `step_stats` | дошли до шага, время на нём |

## API

Документация: http://127.0.0.1:8000/docs.

| Метод и адрес | Что делает | Вход |
|---|---|---|
| `POST /register` | регистрация | нет |
| `POST /login` | вход, возвращает токен | нет |
| `POST /logout` | выход | нет |
| `GET /tasks` | все инструкции | нет |
| `GET /tasks/{id}` | одна инструкция | нет |
| `POST /add_tasks` | создать или форк | да |
| `PUT /tasks/{id}` | изменить свою | да |
| `DELETE /tasks/{id}` | удалить свою | да |
| `POST /tasks/{id}/comments` | комментарий к шагу | да |
| `PUT /tasks/{id}/comments/{comment_id}` | принять предложение | да, автор |
| `DELETE /tasks/{id}/comments/{comment_id}` | отклонить предложение | да, автор |
| `POST /tasks/{id}/votes` | оценка: 1, −1 или 0 | да |
| `POST /tasks/{id}/progress` | отметка прохождения | нет |

Токен — в заголовке `Authorization`.
